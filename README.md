# Comic Readers
Free online comic reader (HTML, CSS, JS). By Satish Kumar.

## Publish on GitHub Pages
1. Create a repo named `comic-readers` on GitHub and upload all these files (keep the folders).
2. Repo > Settings > Pages > Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`, Save.
3. After a minute the site is live at `https://YOUR-USERNAME.github.io/comic-readers/`.
4. Replace `YOUR-USERNAME` in index.html, about.html, robots.txt and sitemap.xml with your GitHub username.

## Add a comic
Open `js/comics.js`, copy one comic object, change id/title/pages. Done.
